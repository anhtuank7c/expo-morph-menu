### How it works

1. Sign in with the prefilled demo account (the API is a mock inside the app, there is no network).
2. The compose button floats over the bottom tabs: `<MorphMenu bottomOffset>` keeps it above the tab bar.
3. New post, Photo, Poll, Go live and New message are routes of the `compose` group; Photo pushes an Edit photo screen inside the sheet, with the native back button.
4. The menu uses its own slots and config (`COMPOSE_COMPONENTS`, `COMPOSE_CONFIG`) from the compose feature folder.
