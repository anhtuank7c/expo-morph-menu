### How it works

1. The button and the card are one surface. The `Background` slot reads `progress` and blends lime (the button, 0) into graphite (the card, 0.5 and up) with `interpolateColor`.
2. Its `sheet` variant is plain graphite, so the card and the growing screen match on the frame they swap.
3. The `Trigger` slot draws a dark + that fades and turns as the card opens; `colorScheme: 'dark'` and `colors.dark` set the text, highlight and screen background.
4. Send has a working keypad and a contact picker; Request shows a code and a link.
