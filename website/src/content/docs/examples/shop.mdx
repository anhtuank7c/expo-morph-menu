### How it works

1. The `Trigger` slot reads a small cart store, so the badge on the button changes as you add products on the home screen.
2. The `Item` slot paints its own hover state from `hovered`, so `Highlight` is `null`, and shows a count per row.
3. A `Background` slot turns the orange button into a white card, like the wallet.
4. The cart screen edits quantities in the same store: close it and the badge follows.
5. The banner on the home screen is [expo-morph-carousel](https://anhtuank7c.github.io/expo-morph-carousel/), the sister package: the promotions loop and their photos melt into each other like liquid.
