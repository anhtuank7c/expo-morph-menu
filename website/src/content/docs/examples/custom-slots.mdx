### How it works

1. `components` replaces `Background`, `Item`, `Trigger`, `Separator` and `Scrim`; the package keeps the animated containers, the gestures and the hand-off.
2. `Item` reads `hovered` (a shared value) to paint its own hover state, so `Highlight` is `null`.
3. Rows with a subtitle are taller: `itemHeight(item)` gives every height in advance, because rows are never measured.
4. The slots are pure and the background is opaque: the card and the full screen show the same rows and swap in one frame.
