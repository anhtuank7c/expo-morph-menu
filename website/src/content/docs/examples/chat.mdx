### How it works

1. An `Item` slot draws an icon tile, the label and `item.data.subtitle`; the built-in Highlight still marks the row under the finger.
2. `itemHeight` returns 60 for rows with a subtitle: heights are known in advance, rows are never measured.
3. `fabIcon` replaces the + with a compose icon, colored by `colors.fabIcon`.
4. New message filters contacts as you type; New group toggles members; New channel has a public switch.
