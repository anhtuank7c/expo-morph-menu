### How it works

1. `config={{ anchor: 'bottom-left' }}` moves the button; the card opens from that corner and the full screen grows from it.
2. Everything else in `config` works the same way: sizes (`layout`), corner radii (`radius`), shadow, dismiss gestures, spring, haptics, surface and colors.
3. All options are optional and merge with the defaults, per platform if you use `Platform.select`.
