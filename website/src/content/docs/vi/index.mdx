## Chỉ với ba file

```bash
npx expo install expo-morph-menu \
  expo-router react-native-reanimated react-native-worklets \
  react-native-gesture-handler react-native-safe-area-context react-native-screens
```

<Demo route="">

<Steps>

1. **app/\_layout.tsx**: provider, nhóm sheet và menu.

   ```tsx
   <MorphProvider items={items}>
     <Stack>
       <Stack.Screen name="index" />
       <Stack.Screen name="(sheet)" options={morphSheetScreenOptions} />
     </Stack>
     <MorphMenu />
   </MorphProvider>
   ```

2. **app/(sheet)/\_layout.tsx**: mọi route bên trong đều nở ra từ thẻ.

   ```tsx
   <MorphSheetLayout>
     <Stack.Screen name="[key]" />
   </MorphSheetLayout>
   ```

3. **app/(sheet)/[key].tsx**: một màn hình bình thường có nút đóng.

   ```tsx
   <MorphCloseButton />
   ```

</Steps>

Khung điện thoại bên trái chính là chừng ấy. Trang [Cách dùng](/expo-morph-menu/vi/usage/) có nguyên các file, chép về là chạy.

</Demo>

  </Card>
  <Card title="Slot" icon="puzzle">

  </Card>
  <Card title="Tải trước khi rê chuột" icon="rocket">

  </Card>
